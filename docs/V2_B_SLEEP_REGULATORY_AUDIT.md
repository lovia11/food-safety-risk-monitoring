# V2-B 睡眠宣传监管知识专项审计

> 日期：2026-09-18  
> 状态：Research baseline / sleep production implementation 已进入 `V2_B4_SLEEP_VERTICAL_SLICE.md`；本文件保留研究依据与边界

## 1. 结论先行

此前 V2 将 `sleep_related` 保留为“检测知识待补充”。本轮核验后需要修正这一认识：**睡眠方向并不是缺少官方监管依据，而是项目尚未把已经公开的官方“声称改善睡眠 → 检验关注物质”关系治理进 V2 知识链。**

但是，现有 `sleep_related` 只是页面主题分类，包含“助眠、入睡、睡眠、安睡、好眠、深睡、失眠、辗转反侧、安神、催眠”等表达。官方材料使用的是“声称改善睡眠功能产品/改善睡眠类样品”。因此 **不得把整个 `sleep_related` Claim 类型无条件映射到全部检测物质**；必须继续维持 expression/evidence 级别治理，避免“页面只出现睡眠二字”就自动给出药物检测建议。

## 2. 主要官方依据

### 2.1 2012《保健食品中可能非法添加的物质名单（第一批）》

在市场监管总局现存的《食品保健食品欺诈和虚假宣传整治问答》中，明确引用：

- 文件：食药监办保化〔2012〕33号
- 类别：`声称改善睡眠功能产品`
- 对应物质：地西泮、硝西泮、氯硝西泮、氯氮卓、奥沙西泮、马来酸咪达唑仑、劳拉西泮、艾司唑仑、阿普唑仑、三唑仑、巴比妥、苯巴比妥、异戊巴比妥、司可巴比妥、氯美扎酮。

来源（SAMR）：
https://www.samr.gov.cn/cms_files/filemanager/1647978232/attach/20233/P020181214555096215303.pdf

这是一条真正的 **功能声称 → 可能非法添加物质** 官方关系，不是由检验方法反向推断出来的。

### 2.2 全国整治工作《食品保健食品欺诈和虚假宣传整治问答》抽检表

同一官方文件的“整治中，对保健食品和食品抽样检验应重点检测什么？”进一步给出：

- 保健食品监督抽检：`改善睡眠类样品` → 一组睡眠相关检测成分；
- 食品风险监测：`声称改善睡眠类样品` → 同类检测成分；
- 备注明确：**根据声称的功能（包括批准和虚假宣传）确定非法添加项目**。

该表在 2012 第一批名单的基础上还出现褪黑素、佐匹克隆、氯苯那敏、扎来普隆、文拉法辛、青藤碱、罗通定等扩展检测项目。

这说明监管筛查逻辑本身确实存在“页面/产品功能声称 → 重点检测项目”的路径。

### 2.3 BJS 201710

市场监管总局食品补充检验方法数据库仍公开：

- `BJS 201710`
- 《保健食品中75种非法添加化学药物的检测》
- 官方页面：https://www.samr.gov.cn/spcjs/bz/cs/art/2017/art_0365495da2fa4ee782b888f0cacd0b5b.html

项目 `inspection_reference.json` 已经完成 75 个目标物和适用范围的治理，并已确认包含多种睡眠方向相关目标物，例如劳拉西泮、氯硝西泮、阿普唑仑、艾司唑仑、奥沙西泮、地西泮、佐匹克隆等。

因此，V2 当前的主要缺口不是“没有方法”，而是 **Claim → Inspection Concern → Substance** 没有把官方关系接进来。

### 2.4 KJ201903

市场监管总局 2019 年第41号公告正式发布：

- `KJ201903`
- 《保健食品中巴比妥类化学成分的快速检测 胶体金免疫层析法》
- 官方页面：https://www.samr.gov.cn/spcjs/xxfb/art/2019/art_2a1de171556f40f2b8f5829fe9810086.html

本方法属于快速筛查。项目已有治理说明：阳性结果需要进一步确证，不能把快速筛查结果写成最终检出结论。

## 3. 时间边界与当前性

本轮发现的“改善睡眠 → 重点检测物质”最明确来源是 2012 名单及后续全国整治文件，属于历史监管文件，不能简单写成“2026年最新抽检规则”。

但它也不能被当作失效废料：

1. 市场监管总局仍公开保存上述名单和整治材料；
2. 2023 年保健食品功能目录仍保留“有助于改善睡眠”，并明确其原功能声称为“改善睡眠”；
3. BJS 201710、KJ201903 仍有市场监管总局正式公开方法页面；
4. 2026 年已公开的方法废止公告所列废止方法中未包含 BJS 201710 或 KJ201903。

因此，V2 可以把 2012/整治文件作为 **可追溯的监管筛查依据**，但 UI 和数据模型必须保留 source date / source type，不得伪装成“2026年度抽检目录”。

## 4. 褪黑素必须单独处理

整治时期的睡眠类抽检表把“褪黑素”列为检测项目之一，但当前监管语境已经更明确：

- 市场监管总局 2025 年发布 GB/T 45443-2025《保健食品中褪黑素的测定》；
- 总局公开说明褪黑素是保健食品原料，可用于改善睡眠类保健食品；
- 该标准自 2025-10-01 实施。

因此：

**不得建立 `sleep_related → 褪黑素 = 非法添加关注物` 这样的自动关系。**

V2 中褪黑素应走“商品身份/配方/原料合规上下文 + 含量测定方法”的独立路径；它可以是检验项目，但不能因为页面说“助眠”就被显示成疑似非法添加物。

## 5. 对现有 V2 架构的直接影响

### 5.1 可以建立新的睡眠监管关注方向

建议新增内部关注方向：

` sleep_improvement `（内部 ID 待实现时最终确定）

语义：页面存在足以支持“改善睡眠/助眠功能声称”判断的商家管理内容时，依据已治理官方资料，进入睡眠方向抽检知识链。

### 5.2 不允许 Claim 类型整体直连

禁止：

`claim_type == sleep_related → 自动触发全部睡眠检测物质`

原因：当前 `sleep_related` 同时包含真正功能声称和仅用于描述睡眠问题的主题词。例如“睡眠”“入睡”“失眠”“辗转反侧”仅靠词本身无法确定页面是否在对商品作出改善睡眠功能声称。

必须继续使用 expression/evidence 级规则。

### 5.3 第一批生产桥接应保守

第一批建议优先研究并治理“明确功能性表达”，例如：

- 助眠
- 安睡
- 好眠
- 深睡
- 催眠

其中每个 expression 是否正式进入生产 bridge，要在实现前逐项确认语义边界。

以下表达暂不应仅凭词命中直接触发物质推荐：

- 睡眠
- 入睡
- 失眠
- 辗转反侧

“安神”也需要单独判断，因为其传统表述范围可能大于“改善睡眠”。

### 5.4 Risk → Substance 不应从 Method 倒推

睡眠方向的物质关系应以 2012 名单/官方抽检表作为 provenance；BJS 201710、KJ201903 只负责回答“怎么检测”。

推荐链仍保持：

`Claim evidence → Sleep inspection concern → governed substances → applicable methods → human review`

而不是：

`BJS 201710 能测某物质 → 猜页面应该关注该物质`

## 6. 第一批物质范围建议

为了避免一次性把历史抽检表所有项目都混成“疑似非法添加”，V2-B1 建议先采用 **2012 第一批名单中明确属于“声称改善睡眠功能产品”的核心物质集合** 作为 Risk→Substance 来源。

即先围绕：

- 地西泮
- 硝西泮
- 氯硝西泮
- 氯氮卓
- 奥沙西泮
- 咪达唑仑（来源文件表述为马来酸咪达唑仑）
- 劳拉西泮
- 艾司唑仑
- 阿普唑仑
- 三唑仑
- 巴比妥
- 苯巴比妥
- 异戊巴比妥
- 司可巴比妥
- 氯美扎酮

后续再单独审计 2018 抽检表扩展出的佐匹克隆、扎来普隆、文拉法辛、青藤碱、罗通定、氯苯那敏等项目，明确它们在系统中应标记为“抽检关注项目”还是“可能非法添加物质”，避免混用法律语义。

## 7. V2-B1 实现门槛

在写生产映射前必须满足：

1. 为 sleep concern 建立独立 Risk/InspectionConcern reference，并保存 2012/整治文件 provenance；
2. 逐一核对第一批 15 个目标物在当前 Substance index 中的规范名、CAS、方法覆盖；
3. 对 BJS 201710 与 KJ201903 的方法适用范围保持原有 Product Context 门槛；
4. 不把褪黑素并入“非法添加”自动推荐；
5. 不把 `sleep_related` 全类型直接桥接；
6. 新增测试保证“难入睡/睡眠”这类宽泛命中不会因单个词自动生成药物建议；
7. UI 用“已建立睡眠方向监管关注依据/当前表达不足以自动进入检测建议”等人话表达，不显示“无映射”。

## 8. 本轮结论

V2-B 的睡眠方向 **有足够官方依据继续建设**，不是知识空白。

真正需要做的是：

- 把历史官方功能声称→检测物质关系治理进当前 Claim 主链；
- 同时用 expression/evidence 级门槛防止过度触发；
- 把“方法可检测什么”和“为什么这个商品值得检测什么”继续严格分开；
- 对褪黑素等当前合法保健食品原料保留监管上下文，避免历史抽检表被机械解释成非法添加清单。
